# RelayDock 1.1.0

RelayDock is a free and open-source OBS Studio multistream plugin. It streams to Twitch, TikTok, YouTube, Facebook and custom RTMP or RTMPS destinations from one OBS session, straight from your PC.

This version adds Update now: RelayDock can fetch and install a newer version when you ask it to. Some checks need a person and are still open. They are listed under "What is still open".

## Download

| File | Use it when |
| --- | --- |
| `RelayDock-1.1.0-windows-x64-Setup.exe` | OBS Studio is installed on your PC. This is the usual way. |
| `RelayDock-1.1.0-windows-x64.zip` | You run a portable OBS Studio, or you want to copy the files yourself. |
| `SHA256SUMS.txt` | You want to check your download. |

The files are under Assets at the end of this page. [versions.md](../versions.md) lists every version.

You need Windows 10 or 11 (64-bit) and OBS Studio 32.0.0 or newer.

## Install or update

1. Close OBS Studio.
2. Run `RelayDock-1.1.0-windows-x64-Setup.exe`. It asks for administrator rights only when Windows does not let your account write to the OBS plugin folder.
3. Start OBS Studio and open Docks, RelayDock.

The installer replaces an older version. Your destinations, settings and stream keys stay. From this version on, RelayDock offers Update now for the next one, so you no longer need to download and run the installer yourself.

Windows SmartScreen may show "Windows protected your PC", because the files are not code-signed. Choose More info, then Run anyway. [installation.md](../installation.md) explains the message and shows how to check the file against `SHA256SUMS.txt` first.

After this update RelayDock asks you to review three documents again, because they describe Update now.

## What changed

### Update now

When a newer version exists, RelayDock tells you, as before. The window now has an Update now button.

1. Choose Update now. RelayDock downloads the installer from the release page on GitHub and checks it against the checksums of the release.
2. Close OBS Studio, or choose Close OBS and install.
3. The installer runs by itself and offers to start OBS again.

Nothing is installed while OBS runs, and Cancel update takes it back until you close OBS. Settings, Updates and the dock say when an update waits.

Update now works for a RelayDock that the installer put on your PC. A RelayDock in a portable OBS still gets the download in your browser.

RelayDock keeps a downloaded installer only when it is the file the release holds. A file that does not match its checksum is deleted and never started. The release files carry no code signature, so the check shows that the file arrived unchanged, not who published it. [security.md](../security.md) has the details.

### Smaller changes

- An installer or uninstaller that waits for OBS to close asks Windows every two seconds whether OBS still runs, and no longer twice a second.

## What is tested

- Unit and security tests of every decision RelayDock makes, on every build.
- 538 checks in a real OBS Studio, on each of 32.0.4 and 32.2.2: streaming, shared encoders, failure isolation, reconnect, the vertical canvas, automatic optimisation, every window of the interface, the chat dock, and clean shutdown.
- Update now inside a real OBS, on both OBS versions, against a stand-in for the release pages on the same PC: a changed installer is refused, a cancelled update installs nothing, and an accepted one installs the newer version once OBS has closed.
- The first step of Update now against the real GitHub: RelayDock fetched the checksum list of the published 1.0.0 through GitHub's redirect, and it named the checksum GitHub lists for the installer. No installer was downloaded in that check.
- The installer and the uninstall from inside RelayDock, with a test build of the installer.
- The ZIP, installed into a portable OBS by the steps of the guide.
- Two builds of the same source give the same `relaydock.dll`.

[testing.md](../testing.md) describes every suite and links the results.

## What is still open

The project owner decided to publish this version with these checks open.

- A whole update from the real GitHub. The tests download the installer from a stand-in on the same PC. The first real update is the one from this version to the next.
- Chat with the real Twitch and the real YouTube. Nobody has signed in or read a real chat with RelayDock yet.
- Twitch, YouTube and Facebook have not received a stream from RelayDock in the project's own testing. TikTok accepted a stream from 1.0.0-rc.1.
- Windows 10. All recorded results come from one PC with Windows 11 and AMD graphics.
- The 2 hour and 6 hour endurance runs are not finished.
- Custom RTMPS against a real server. The local tests use plain RTMP.
- The Windows clipboard history after Copy Key. The tests cover the clipboard itself.
- The legal documents have not been reviewed by a lawyer. Each says so.
- TikTok's terms ask for its written permission before its logo is used. The project has not obtained one. Settings, Appearance switches the logos off.

[release-checklist.md](../release-checklist.md) has the state of every gate.

## Known limitations

RelayDock streams over RTMP and RTMPS only, reads chat from Twitch and YouTube only, and does not record. It needs 64-bit Windows 10 or 11 and OBS Studio 32 or newer. [known-limitations.md](../known-limitations.md) has the full list.

## Report a problem

Open an issue with the bug report template and attach a diagnostics report from Settings, Diagnostics. The report contains no stream key, no sign-in and no chat. Never post a stream key. For a security problem, follow [SECURITY.md](../../SECURITY.md).
