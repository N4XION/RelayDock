# RelayDock 1.0.0-rc.2

The second release candidate of RelayDock, a free and open-source OBS Studio multistream plugin. It streams to Twitch, TikTok, YouTube, Facebook and custom RTMP or RTMPS destinations from one OBS session, straight from your PC.

This is a pre-release. Some checks need a person and are still open. They are listed under "What is still open".

## Download

| File | Use it when |
| --- | --- |
| `RelayDock-1.0.0-rc.2-windows-x64-Setup.exe` | OBS Studio is installed on your PC. This is the usual way. |
| `RelayDock-1.0.0-rc.2-windows-x64.zip` | You run a portable OBS Studio, or you want to copy the files yourself. |
| `SHA256SUMS.txt` | You want to check your download. |

The files are under Assets at the end of this page. [versions.md](../versions.md) lists every version.

You need Windows 11 (64-bit) and OBS Studio 32.0.0 or newer.

## Install or update

1. Close OBS Studio.
2. Run `RelayDock-1.0.0-rc.2-windows-x64-Setup.exe`. It asks for administrator rights only when Windows does not let your account write to the OBS plugin folder.
3. Start OBS Studio and open Docks, RelayDock.

The installer replaces 1.0.0-rc.1. Your destinations, settings and stream keys stay.

Windows SmartScreen may show "Windows protected your PC", because the files are not code-signed. Choose More info, then Run anyway. [installation.md](../installation.md) explains the message and shows how to check the file against `SHA256SUMS.txt` first.

After this update RelayDock asks you to review two documents again, the Privacy Policy and the Third-Party Services Notice, because the update check changed.

## What changed

### Your vertical stream shows the whole picture

A new vertical layout shows your whole OBS picture as a band across the middle of the 9:16 frame, with empty space above and below. Before, it filled the frame and cut off the sides, so viewers on TikTok saw a zoomed-in part of the screen.

A layout that is still the untouched standard layout of 1.0.0-rc.1 changes to the new look by itself when OBS loads it, and the OBS log says so. A layout you arranged stays as it is.

To crop on purpose, open the layout editor from Settings, Vertical Layout, select the item and set Scaling to Fill.

### RelayDock tells you when a newer version exists

RelayDock looks for a newer version each time OBS starts. When there is one, a window says so. It has four buttons:

- Download installer saves the installer with your browser. Close OBS, open the file, and the update is done.
- What changed opens the release page.
- Later asks again at the next start.
- Skip this version stays quiet until a newer one exists.

RelayDock still downloads nothing and installs nothing by itself. Switch the check at start-up off under Settings, Updates.

1.0.0-rc.1 only looked when you asked, so it does not announce this version by itself. Install this one by hand. From here on RelayDock tells you.

## What is tested

- Unit and security tests of every decision RelayDock makes, on every build.
- CHECKS_COUNT checks in a real OBS Studio, on each of 32.0.4 and 32.2.2: streaming, shared encoders, failure isolation, reconnect, the vertical canvas, automatic optimisation, every window of the interface, and clean shutdown.
- TikTok accepted a stream from 1.0.0-rc.1 on 4 October 2026: the project owner streamed a game to TikTok LIVE, and the picture arrived in the TikTok app. Sound, stopping and reconnecting were not checked in that run.
- The ZIP, installed into a portable OBS by the steps of the guide.
- Two builds of the same source give the same `relaydock.dll`.

[testing.md](../testing.md) describes every suite and links the results.

## What is still open

- The installer of this version has not been run by a test. The installer test only runs on a PC without RelayDock, and the development PC has it installed now. The installer script is the one of 1.0.0-rc.1, whose installer passed that test.
- Twitch, YouTube and Facebook have not received a stream from RelayDock in the project's own testing.
- The 2 hour and 6 hour endurance runs are not finished.
- Custom RTMPS against a real server. The local tests use plain RTMP.
- NVIDIA and Intel graphics, and Windows 10, on the development PC. All recorded results come from one PC with AMD graphics and Windows 11.
- The Windows clipboard history after Copy Key. The tests cover the clipboard itself.
- The legal documents have not been reviewed by a lawyer. Each says so.

[release-checklist.md](../release-checklist.md) has the state of every gate.

## Known limitations

RelayDock streams over RTMP and RTMPS only, does not sign in to platforms, cannot read chat, and does not record. [known-limitations.md](../known-limitations.md) has the full list.

## Report a problem

Open an issue with the bug report template and attach a diagnostics report from Settings, Diagnostics. The report contains no stream key. Never post a stream key. For a security problem, follow [SECURITY.md](../../SECURITY.md).
