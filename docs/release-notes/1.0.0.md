# RelayDock 1.0.0

RelayDock is a free and open-source OBS Studio multistream plugin. It streams to Twitch, TikTok, YouTube, Facebook and custom RTMP or RTMPS destinations from one OBS session, straight from your PC.

This is the first version without the release candidate label. Some checks need a person and are still open. They are listed under "What is still open".

## Download

| File | Use it when |
| --- | --- |
| `RelayDock-1.0.0-windows-x64-Setup.exe` | OBS Studio is installed on your PC. This is the usual way. |
| `RelayDock-1.0.0-windows-x64.zip` | You run a portable OBS Studio, or you want to copy the files yourself. |
| `SHA256SUMS.txt` | You want to check your download. |

The files are under Assets at the end of this page. [versions.md](../versions.md) lists every version.

You need Windows 10 or 11 (64-bit) and OBS Studio 32.0.0 or newer.

## Install or update

1. Close OBS Studio.
2. Run `RelayDock-1.0.0-windows-x64-Setup.exe`. It asks for administrator rights only when Windows does not let your account write to the OBS plugin folder.
3. Start OBS Studio and open Docks, RelayDock.

The installer replaces an older version. Your destinations, settings and stream keys stay. From 1.0.0-rc.2 on, RelayDock tells you about this version when OBS starts.

Windows SmartScreen may show "Windows protected your PC", because the files are not code-signed. Choose More info, then Run anyway. [installation.md](../installation.md) explains the message and shows how to check the file against `SHA256SUMS.txt` first.

After this update RelayDock asks you to review four documents again, because they describe what is new.

## What changed

### A chat dock for Twitch and YouTube

RelayDock Chat is a second dock, under the OBS Docks menu. It shows the comments of your Twitch and YouTube streams in one list, with Bits, Super Chats, gifts, new subscribers and raids.

- Twitch: you sign in on twitch.tv with a code RelayDock shows you. RelayDock gets one permission, to read chat. This release comes without a Twitch application id, so you register one with Twitch first, free of charge.
- YouTube: you create an API key of your own, free of charge, and paste the link to your stream. YouTube's rules do not allow RelayDock to come with a key.
- TikTok and Facebook are not read. TikTok publishes no way to read live comments, and Meta's needs an approval RelayDock does not have.

[chat.md](../chat.md) has every step, and says what you can do for TikTok inside TikTok's rules.

### Platform logos

The badges of Twitch, TikTok, YouTube and Facebook show the platform's logo. Settings, Appearance switches back to letters. The logos are trademarks of their owners.

### Uninstall from inside RelayDock

Settings, Updates has an Uninstall section. RelayDock starts its uninstaller, which waits until you close OBS. Until then, Keep RelayDock takes the request back. Your destinations, settings and stream keys stay unless you tick the box.

### Smaller changes

- Closing OBS no longer waits for a web request that hangs.
- When GitHub turns the update check away because too many requests came from your internet address, which happens on a VPN, RelayDock says so.

## What is tested

- Unit and security tests of every decision RelayDock makes, on every build.
- The integration suites in a real OBS Studio, on each of 32.0.4 and 32.2.2: streaming, shared encoders, failure isolation, reconnect, the vertical canvas, automatic optimisation, every window of the interface, and clean shutdown.
- The chat dock inside a real OBS, against stand-ins for Twitch and YouTube that follow the interfaces both platforms publish.
- The installer and the uninstall from inside RelayDock, with a test build of the installer.
- The ZIP, installed into a portable OBS by the steps of the guide.
- Two builds of the same source give the same `relaydock.dll`.

[testing.md](../testing.md) describes every suite and links the results.

## What is still open

The project owner decided to publish this version as 1.0.0 with these checks open.

- Chat with the real Twitch and the real YouTube. Nobody has signed in or read a real chat with RelayDock yet.
- Twitch, YouTube and Facebook have not received a stream from RelayDock in the project's own testing. TikTok accepted a stream from 1.0.0-rc.1.
- Windows 10. All recorded results come from one PC with Windows 11 and AMD graphics.
- The 2 hour and 6 hour endurance runs are not finished.
- Custom RTMPS against a real server. The local tests use plain RTMP.
- The Windows clipboard history after Copy Key. The tests cover the clipboard itself.
- The legal documents have not been reviewed by a lawyer. Each says so.

[release-checklist.md](../release-checklist.md) has the state of every gate.

## Known limitations

RelayDock streams over RTMP and RTMPS only, reads chat from Twitch and YouTube only, and does not record. It needs 64-bit Windows 10 or 11 and OBS Studio 32 or newer. [known-limitations.md](../known-limitations.md) has the full list.

## Report a problem

Open an issue with the bug report template and attach a diagnostics report from Settings, Diagnostics. The report contains no stream key, no sign-in and no chat. Never post a stream key. For a security problem, follow [SECURITY.md](../../SECURITY.md).
