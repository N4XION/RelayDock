# RelayDock 1.0.0-rc.1

The first release candidate of RelayDock, a free and open-source OBS Studio multistream plugin. It streams to Twitch, TikTok, YouTube, Facebook and custom RTMP or RTMPS destinations from one OBS session, straight from your PC.

This is a pre-release. Everything in it is built and covered by automated tests against a test server. Some checks need a person and are still open. They are listed under "What is still open".

## Download

| File | Use it when |
| --- | --- |
| `RelayDock-1.0.0-rc.1-windows-x64-Setup.exe` | OBS Studio is installed on your PC. This is the usual way. |
| `RelayDock-1.0.0-rc.1-windows-x64.zip` | You run a portable OBS Studio, or you want to copy the files yourself. |
| `SHA256SUMS.txt` | You want to check your download. |

The files are under Assets at the end of this page.

You need Windows 11 (64-bit) and OBS Studio 32.0.0 or newer.

## Install

1. Close OBS Studio.
2. Run `RelayDock-1.0.0-rc.1-windows-x64-Setup.exe`. It asks for administrator rights only when Windows does not let your account write to the OBS plugin folder.
3. Start OBS Studio and open Docks, RelayDock.

Windows SmartScreen may show "Windows protected your PC", because the files are not code-signed. That message means Windows does not know the file yet. [installation.md](../installation.md) explains it and shows how to check the file against `SHA256SUMS.txt` first.

For the ZIP, follow [manual-installation.md](../manual-installation.md). Your first stream is in [getting-started.md](../getting-started.md).

## What it does

- Streams to several destinations at once. Each has its own connection, so one failing or reconnecting never stops the others.
- Encodes once for destinations with identical settings.
- Streams horizontal 16:9 and vertical 9:16 at the same time, with a layout editor for the vertical picture.
- Four performance modes, setting locks, and rule-based automatic optimisation that suggests or applies changes.
- A preflight check that says READY, WARNING or FAILED with a reason and a fix.
- Keeps stream keys in Windows Credential Manager. Never in a file, never in a log, never on screen.
- Protects a running stream: a question before OBS closes, a PC that stays awake, and OBS video settings that stay locked while a destination connects or waits to reconnect.
- No account, no telemetry, no RelayDock server.

[CHANGELOG.md](../../CHANGELOG.md) has the full list.

## What is tested

- Unit and security tests of every decision RelayDock makes, on every build.
- 462 checks in a real OBS Studio, on each of 32.0.4 and 32.2.2: streaming, shared encoders, failure isolation, reconnect, the vertical canvas, automatic optimisation, every window of the interface, and clean shutdown.
- A 30 minute stream to three destinations with no dropped frame and no reconnect.
- The installer: install, install over an existing one, refusal while OBS runs, uninstall, and uninstall with settings and keys. All without administrator rights.
- The ZIP, installed into a portable OBS by the steps of the guide.
- Two builds of the same source give the same `relaydock.dll`.

[testing.md](../testing.md) describes every suite and links the results.

## What is still open

- No real platform has received a stream from this version in the project's own testing. The tests stream to a test server on the same PC. A platform test needs a person with an account. If you try one, the platform test report under Issues helps the next person.
- Nobody has started an installed OBS Studio with RelayDock put in place by the installer. The installer test checks the files and the folder. It does not start an installed OBS, because that would use a real user's OBS settings.
- The 2 hour and 6 hour endurance runs are not finished.
- Custom RTMPS against a real server. The local tests use plain RTMP.
- NVIDIA and Intel graphics, and Windows 10. All results come from one PC with AMD graphics and Windows 11.
- The Windows clipboard history after Copy Key. The tests cover the clipboard itself.
- The legal documents have not been reviewed by a lawyer. Each says so.

[release-checklist.md](../release-checklist.md) has the state of every gate.

## Known limitations

RelayDock streams over RTMP and RTMPS only, does not sign in to platforms, and does not record. [known-limitations.md](../known-limitations.md) has the full list, including a measured case where a hardware encoder sends more than the bitrate you set.

## Report a problem

Open an issue with the bug report template and attach a diagnostics report from Settings, Diagnostics. The report contains no stream key. Never post a stream key. For a security problem, follow [SECURITY.md](../../SECURITY.md).
